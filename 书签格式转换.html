书签转 NavSync JSON

导入浏览器书签 → 可视化编辑分类/分组 → 导出 NavSync JSON

步骤 1：选择书签文件
📁

点击选择或拖入书签 HTML 文件

支持 Chrome / Edge / Firefox / Safari 导出的 HTML

  1. Chrome：地址栏 chrome://bookmarks → 右上角⋮ → 导出书签
  2. Edge：收藏夹 Ctrl+Shift+O → 右上角⋯ → 导出收藏夹
  3. Firefox：书签管理器 Ctrl+Shift+O → 导入和备份 → 导出书签到 HTML
  4. Safari：文件 → 导出书签
